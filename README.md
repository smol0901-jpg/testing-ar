# RoastLab — журнал тестов жарки

Лёгкое PWA-приложение для фиксации тестов жарки (проработок), автоматического
расчёта ужарки по этапам и уровням противней, и мгновенной генерации отчёта
в привычном формате «Тест #N …» для отправки в рабочий чат.

## Уровни / противни
Количество уровней задаётся свободно (1–30) — быстрые кнопки 4 (обычная печь)
и 20 (вагонка хлебозаводская), либо точное число вручную. При количестве
уровней больше 6 отчёт не перечисляет каждый уровень построчно (иначе он
станет нечитаемым на 20 противнях), а показывает итог и разброс ужарки
между уровнями (мин/макс/среднее) — то, что реально важно для оценки
равномерности прогрева вагонки. Подробные значения по каждому уровню всегда
остаются в самой форме и сохраняются в данных теста.

## Норма, факт и вход на второй этап
Ужарка считается от **нормы фасовки** (номинальный вес мяса при закладке в
пакет, обычно 1,000 кг), а не от факта на противне — так потери при
вакуумировании и мариновании тоже честно входят в итоговый процент, как и
принято в цехе. По каждому уровню в форме фиксируются четыре веса:
факт до 1 этапа → выход после 1 этапа → вход на 2 этап (после шокера, до
глазури) → выход после 2 этапа. Глазурь задаётся как доза, г/кг, и
пересчитывается на фактический вес каждого уровня перед вторым этапом —
это позволяет корректно считать общую ужарку, даже если тесты идут по
одному противню за проход (как на 2 этапе при жарке партиями).

## Температуры
Посадочная температура (Р1/Р2) контролируется: в Настройках задаётся
допустимый диапазон (по умолчанию 190–260 °C) — при выходе за него поле
подсвечивается, а в отчёте значение помечается «⚠». Отчёт также считает
разницу посадки между Р1 и Р2 в °C и в %. Температуры по этапам (щуп после
1 этапа, после шокера, финал) можно вести как одну общую цифру на весь
тест, так и раздельно по каждому уровню — переключается тумблером в форме.

## Комментарии и формат отчёта
Для каждого этапа (1 и 2) есть отдельное поле комментария плюс общее
примечание — все они попадают в полный отчёт, с «—» вместо пустых. Есть
два вида отчёта: **Полный** (всё, включая разбивку по уровням, комментарии
этапов, потери фасовки) и **Краткий** (только ключевые цифры для быстрой
отправки в чат) — формат по умолчанию задаётся в Настройках, а на самой
вкладке «Отчёт» его можно переключить на лету без похода в настройки.

## Что внутри
- `index.html` — интерфейс приложения
- `app.js` — вся логика (хранение, расчёты, отчёты, AI-анализ, PWA)
- `manifest.json` — манифест PWA (иконка, имя, тема)
- `sw.js` — service worker для офлайн-работы и установки на устройство
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` — иконки

Данные (тесты) хранятся **локально в браузере** (localStorage) — ничего не
уходит на сервер, кроме опционального запроса к Anthropic API, если вы сами
включите AI-анализ и вставите свой ключ в Настройках.

## Деплой на GitHub Pages
1. Создайте новый репозиторий (например `roastlab`) или папку в существующем
   `smol0901-jpg.github.io`.
2. Загрузите все файлы из этой папки в корень репозитория (или в подпапку,
   например `/roastlab/` — тогда откроется по адресу
   `https://smol0901-jpg.github.io/roastlab/`).
3. Settings → Pages → Source: ветка `main`, папка `/root`. Сохраните.
4. Через 1–2 минуты сайт будет доступен по ссылке GitHub Pages.

## Деплой на Netlify
1. На [app.netlify.com](https://app.netlify.com) → **Add new site → Deploy manually**.
2. Перетащите папку `roastlab` (со всеми файлами) в окно загрузки.
3. Netlify выдаст ссылку вида `https://<name>.netlify.app` — при желании
   переименуйте сайт в Site settings → Change site name.

## Важно для корректной работы PWA
- Манифест и service worker используют **относительные пути** (`./`), поэтому
  все 6 файлов должны лежать в одной папке на сервере — не разносите их по
  разным директориям.
- И GitHub Pages, и Netlify отдают сайт по HTTPS «из коробки» — это
  обязательное условие для установки PWA и работы service worker.
- После первого открытия сайт можно установить на телефон/компьютер:
  на Android/десктопе появится кнопка «Установить» в приложении, на iOS —
  через Safari → «Поделиться» → «На экран Домой».

## AI-анализ (опционально)
Кнопка «Проанализировать тест» на вкладке «Отчёт» напрямую обращается к
`api.anthropic.com` из браузера с вашим личным API-ключом (вводится в
Настройках и хранится только в localStorage этого браузера). Функция
полностью опциональна — без ключа приложение работает как обычный журнал
и генератор отчётов.

⚠️ Прямой вызов из браузера означает, что ключ виден в сетевых запросах
устройства, на котором вы работаете. Используйте личный ключ с разумным
лимитом расходов и не открывайте приложение с сохранённым ключом на чужих
или общих устройствах.

## Экспорт / импорт
Настройки → «Экспорт JSON» сохраняет все тесты в файл — держите бэкап перед
сменой телефона или очисткой браузера. «Импорт JSON» добавляет тесты из
файла, не затирая уже сохранённые (совпадающие по id — обновляются).
